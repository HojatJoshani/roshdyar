# 🌱 رشدیار

### پلتفرم هوشمند رشد اینستاگرام و یوتیوب

پلتفرمی مدرن و حرفه‌ای برای خرید خدمات رشد اینستاگرام و یوتیوب با کیفیت واقعی، تحویل شفاف و پشتیبانی صادقانه. طراحی شده با تمرکز بر تجربه کاربری فارسی و راست‌چین.

---

## ✨ امکانات

### 🛒 سرویس‌ها و سفارش
- **کاتالوگ منتخب**: سرویس‌های اینستاگرام (فالوور، لایک، بازدید) و یوتیوب (بازدید)
- **سه سطح کیفی**: اقتصادی، استاندارد ⭐ پیشنهادی، حرفه‌ای
- **جریان سفارش راهنما**: انتخاب سرویس → سطح → تعداد → لینک → بررسی → پرداخت
- **اسنپ‌شات قیمت**: ثبت لحظه‌ای قیمت و شرایط در زمان خرید

### 📦 رهگیری سفارش
- **تایم‌لاین بصری**: نمایش مراحل سفارش از ثبت تا تکمیل
- **به‌روزرسانی لحظه‌ای**: پیشرفت درصدی و تعداد انجام‌شده
- **تاریخچه رویدادها**: ثبت تمام تغییرات وضعیت با زمان دقیق
- **سفارش مجدد**: ثبت مجدد با یک کلیک

### 💰 کیف پول
- **دفتر تراکنش غیرقابل‌تغییر**: ثبت دقیق تمام تراکنش‌ها
- **شارژ از درگاه زرین‌پال**: پرداخت امن با callback
- **بازگشت خوداری وجه**: در صورت ناکامی سفارش

### 🎫 کدهای تخفیف
- **موتور تخفیف**: درصدی و مبلغ ثابت
- **محدودیت‌ها**: سقف استفاده، حداقل سفارش، انقضا
- **گزارش استفاده**: تحلیل و نمودار

### ⭐ نظرات و امتیازدهی
- **نظرات واقعی**: فقط کاربرانی که سفارش تکمیل‌شده دارند
- **امتیاز ۱ تا ۵ ستاره**
- **نمایش میانگین و توزیع**

### 🛡️ پنل مدیریت
- **داشبورد کامل**: نمودار درآمد و سفارش ۱۴ روز اخیر
- **مدیریت سرویس‌ها**: ویرایش قیمت‌ها و سطوح
- **مدیریت سفارش‌ها**: فیلتر، جستجو، خروجی CSV
- **مدیریت کاربران**: مسدودکردن، جعل هویت
- **کدهای تخفیف**: ساخت و ویرایش
- **نظرات**: مدیریت و مخفی‌کردن
- **تیکت‌ها**: پاسخ به پشتیبانی
- **تنظیمات سیستم**: حالت تعمیرات، محدودیت‌ها
- **سلامت سیستم**: وضعیت ورکر، دیتابیس، سرور

### 🔔 اعلان‌ها
- **مرکز اعلان‌ها**: تغییرات وضعیت سفارش
- **زنگ هشدار**: نمایش تعداد خوانده‌نشده
- **به‌روزرسانی خودکار**

### 👤 حساب کاربری
- **پروفایل**: ویرایش نام، تغییر رمز عبور
- **علاقه‌مندی‌ها**: ذخیره سرویس‌های محبوب
- **جستجوی سراسری**: جستجو در سرویس‌ها، سفارش‌ها و تیکت‌ها
- **حذف حساب (GDPR)**: حذف کامل داده‌ها

## 🎨 طراحی

- **فونت وزیرمتن**: فارسی، خوانا و مدرن
- **راست‌چین کامل (RTL)**: در تمام صفحات و کامپوننت‌ها
- **حالت تاریک**: پشتیبانی کامل از دارک‌مود
- **پالت سبز زمردی**: رنگ سازمانی الهام‌گرفته از رشد
- **انیمیشن‌های ظریف**: переход صفحات، شمارنده، اسکلت لودینگ
- **واکنش‌گرا (Responsive)**: سازگار با موبایل و دسکتاپ

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18+ یا Bun
- npm یا bun

### مراحل

```bash
# کلون کردن ریپو
git clone https://github.com/HojatJoshani/roshdyar.git
cd roshdyar

# نصب پکیج‌ها
bun install

# راه‌اندازی دیتابیس
bun run db:push

# اجرای seed (ایجاد کاربر و سرویس نمونه)
bun run src/lib/seed.ts

# اجرای سرور توسعه
bun run dev
```

سایت روی `http://localhost:3000` اجرا می‌شود.

### اجرای ورکر پس‌زمینه

```bash
# در یک ترمینال جداگانه
cd mini-services/worker
bun run dev
```

ورکر روی پورت `۳۰۰۳` اجرا می‌شود.

## 📊 مدل‌های دیتابیس

- **User** — کاربران (مشتری/مدیر)
- **Wallet** — کیف پول
- **WalletTransaction** — تراکنش‌های کیف پول
- **Service** — سرویس‌ها
- **ServiceTier** — سطوح کیفی سرویس
- **Order** — سفارش‌ها
- **OrderEvent** — رویدادهای سفارش
- **Payment** — پرداخت‌ها
- **SupportTicket** — تیکت‌های پشتیبانی
- **ServiceReview** — نظرات کاربران
- **PromoCode** — کدهای تخفیف
- **PromoRedemption** — استفاده کدها
- **Setting** — تنظیمات سایت
- **AuditLog** — گزارش عملیات
