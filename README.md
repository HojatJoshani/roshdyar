## رشدیار (Roshdyar)

پلتفرم رشد اینستاگرام و یوتیوب با کیفیت واقعی، تحویل شفاف و پشتیبانی صادقانه.

## Features
- Premium RTL Persian UI with Vazirmatn font
- Instagram & YouTube growth services
- Tiered pricing (Economy/Standard/Premium)
- Real-time order tracking with visual timeline
- Wallet system with ZarinPal payment gateway
- Promo codes and discount engine
- Admin panel with full management
- Dark mode support
- Service reviews and ratings
- Notifications center
- Global search

## Tech Stack
- Next.js 16 + TypeScript + Tailwind CSS 4
- Prisma ORM (SQLite)
- NextAuth.js
- Recharts for analytics
- Framer Motion for animations
